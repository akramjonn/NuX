# NuX landing page

Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide marketing site.

## Development

`npm install` then `npm run dev`.

## Production

`npm run build` exports the site to `out/`.

## Launch configuration

- NuX is a working product name.
- Dashboard, newsletter, member, form, and analytics interfaces are illustrative marketing previews.
- Pilot, contact, privacy, and sign-in controls explain their preview status; no personal information is collected.
- Set `DEMO_VIDEO_SRC` in `app/page.tsx` to the real local video path when ready.
- Replace the pilot dialog with a real registration destination and provide official contact/privacy details before launch.
